# Для участника

[← К описанию](../README.md)

## Как получить доступ

1. Администратор присылает ссылку на бота. Откройте её в Telegram и нажмите «Старт».
2. Нажмите «Получить доступ», напишите своё имя и выберите срок — сумма взноса на хостинг видна прямо на кнопке.
3. Дождитесь одобрения. Если доступ с взносом — бот пришлёт QR и кнопку оплаты по СБП (оплатить можно из
   приложения любого банка); как только оплата пройдёт, бот продолжит сам.
4. Бот пришлёт файл приложения, ссылку-приглашение и инструкцию.

## Первая настройка (один раз)

1. Установите приложение из файла (телефон попросит разрешить установку — разрешите).
2. Откройте ссылку-приглашение — приложение спросит «Импортировать подключение?» → «Импортировать».
3. Создайте ссылки на звонки ВК: кнопка «Создать 6 ссылок ВК», вход в ВК — один раз, на этом телефоне.
4. Нажмите «Подключить».

## Каждый день

Открыли приложение — «Подключить». Если сервер недоступен, приложение само перейдёт на запасной. Новая версия
приложения приходит сама — достаточно согласиться на обновление.

## Бот-помощник

- срок доступа, трафик, подключены ли вы сейчас;
- ваша ссылка для подключения ещё раз;
- инструкция и программа для компьютера;
- ваши устройства: освободить место или попросить ещё;
- продление доступа — срок прибавится к текущему;
- «зарегистрироваться заново» — все устройства отвязываются, заявка уходит администратору;
- торренты: если они для вас заблокированы — попросить администратора снять блокировку.

Бот сам напомнит о конце срока (за неделю, за 3 дня, за день) и сообщит, когда доступ продлён.

## Компьютер с Windows

Программа для компьютера подключается по той же ссылке-приглашению. Ссылки на звонки ВК она берёт с вашего
телефона — входить в ВК на компьютере не нужно.

## Устройства

По одной ссылке можно подключить несколько устройств (телефоны и компьютеры вместе). Места занимают те, что
подключились первыми; если мест нет, бот предложит освободить место или попросить администратора добавить.
Чужое устройство по вашей ссылке не подключится — у каждого устройства своя подпись.

## Пожалуйста

- не пересылайте свою ссылку-приглашение другим людям — для них есть бот;
- не качайте через VPN торренты без разрешения администратора: они нагружают общий для всех сервер.
