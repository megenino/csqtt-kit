# CSQTT KIT

Семейный VPN на основе открытого проекта [CSQTT](https://github.com/amurcanov/csqtt): приложение для Android,
программа для Windows, несколько серверов и Telegram-бот, через который участники получают доступ, а администратор
ведёт людей и серверы.

> В этом репозитории — только описание проекта, «почитать и изучить». Исходного кода, скриптов и сборок здесь нет.
> Проект некоммерческий и рассчитан на своих.
>
> **Подробнее о проекте — yisfx@yandex.ru**

## Зачем

CSQTT — это клиент и сервер: человек сам ставит сервер и сам подключается. CSQTT KIT превращает его в систему для
семьи: несколько человек, несколько серверов, а участникам не нужно ничего знать о серверах, портах и паролях — всё
делается через бота и одну ссылку-приглашение.

## Возможности

**Несколько серверов**
- Главный сервер и запасные. Список людей ведётся на главном, остальные серверы повторяют его сами.
- У каждого человека свой основной сервер; при сбое приложение само переходит на следующий и потом возвращается.
- Наблюдение за состоянием и нагрузкой серверов, сторож главного сервера на запасном.

**Одна ссылка-приглашение**
- Одна ссылка даёт подключение ко всем серверам; её можно отправить в Telegram или WhatsApp — приложение само
  предложит её импортировать.
- В ссылке нет ни адресов серверов, ни паролей: адреса приложение получает в зашифрованном виде и обновляет само,
  поэтому смена серверов не требует новых ссылок.

**Telegram-бот**
- Заявка на доступ, одобрение администратором, выдача приложения, ссылки и инструкции — без ручной работы.
- Взносы на оплату хостинга серверов: бот создаёт пополнение баланса сервера у хостера, присылает QR для оплаты
  по СБП и сам видит, что оплата прошла. Деньги идут напрямую на хостинг.
- Напоминания о конце срока, продление, устройства, отчёты и сводки для администратора.

**Устройства**
- Ограниченное число мест под устройства на человека (телефоны и компьютеры вместе), освободить место или
  попросить ещё — в боте.
- Подпись устройства: у каждого устройства свой ключ, поэтому чужое устройство по пересланной ссылке не
  подключится.

**Бережное отношение к серверам**
- Сервер замечает торренты (только по признакам протокола, без записи адресов и содержимого); дальше — правила,
  которые задаёт администратор: предупреждение, решение администратора, блокировка торрентов.

**Приложения**
- Android: своё приложение с обновлениями, 10 профилей, роли «администратор / пользователь», создание ссылок на
  звонки ВК одной кнопкой, переключение серверов, профили трафика, диагностика, установка своей системы с телефона.
- Windows: подключение по той же ссылке-приглашению, переключение серверов, автопереподключение, обновления.
  Компьютер в ВК не входит — ссылки на звонки он берёт с телефона.

## Как это выглядит для участника

1. Администратор присылает ссылку на бота. В боте — «Получить доступ», имя и срок.
2. Администратор одобряет заявку.
3. Бот присылает приложение, ссылку-приглашение и инструкцию.
4. Ссылка открывается в приложении, приложение создаёт ссылки на звонки ВК одной кнопкой — «Подключить».
5. Дальше бот сам напоминает о сроке и помогает с устройствами.
